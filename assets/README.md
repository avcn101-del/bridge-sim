# assets/

Optional runtime assets. Empty in the MVP (ships are vector-drawn).

- `ships/` — image sprites (PNG, transparent). To use one, set a ship class's
  `visual.kind` to `"sprite"` and `visual.sprite` to the file path in `js/data.js`.
- `sfx/` — sound effects for the later audio module.
- `ui/` — interface images, if any.
